# Lovely VPN 演示蜜罐

在上级 `honeypots` 目录运行 `go run ./vpn`，打开 `http://127.0.0.1:8801`。门户口令 `demo`；连接页使用工号 `00000000`、密码 `demo`。

保留门户、连接按钮/时长和资源导航。连接成功仅显示 `192.0.2.10`，`/api/connect` 返回 `tunnel: false`；没有真实 VPN、代理转发、系统权限或终端数据采集。设置页只保存本页内存中的演示状态，资源卡片不访问业务站点。

| 路由 | 行为 |
| --- | --- |
| `/`、`/client`、`/resources` | 门户、连接演示、合成资源 |
| `POST /api/login` | 仅接受公开演示凭据，不保存输入 |
| `POST /api/connect` | 只接受 `{"scenario":"demo"}`；未知字段拒绝 |
| `/healthz` | 进程健康检查 |

这是公开可浏览的合成页面，演示登录不作为资源访问授权。请求事件及部署步骤见[模块说明](../README.md)。原 Windows WebView 宿主、安装包、截图和回传服务器不包含在本版。
