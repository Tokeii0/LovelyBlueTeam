# LovelyLivelog 功能参考

功能行为以源码与测试为准。部署入口、默认值和验收见模块 README 与统一部署手册。

## 采集与留存

1Panel 采集按文件字节位置增量读取，每 3 秒轮询。首次建立文件末尾基线，不将全部历史记录当作实时流量；半行和不完整 UTF-8 会等待后续字节。文件缩小或边界变化后重新跟踪，已轮转离开的旧文件无法仅凭当前路径补齐。

原始日志、断点、分析历史存入 runtime/state.sqlite3，当前没有自动过期清理。界面暂停仅停止刷新，后台仍工作。读取窗口支持 200/500/1000/2000/5000 行，全文搜索与归档容量相关；磁盘规划需基于自己的日增量。

Agent 支持实时文件、通配符以及 access_{date}.log 按日前清洗。每日清洗保留真实次数、首次/末次时间，可疑请求保留证据，正常请求可聚合。断网期间进入有上限的离线队列；满后暂停推进读取位置，恢复后补传。事件编号避免重试重复计算。

## 本地与模型分析

默认 local 模式只使用本地规则，停用模型调用及自动封禁。本地无命中不代表安全。人工确认的处置仍保留权限检查与回读。

显式 ai 模式支持 DeepSeek、OpenAI 兼容 Chat Completions 和 OpenRouter Jev，备用模型独立配置。模型名称、接口和密钥由部署者填写；模型输出需要结构校验、置信度和证据匹配。失败保留待处理数据，不伪装成正常结果。

LOCAL_RULE_AGENT_IDS 按经过认证的代理身份隔离正文工作台与其他采集源。请求正文的自报标签不会改变来源策略。来源、站点、历史与近期请求分别成批，不能跨来源拼凑封禁依据。

原始请求指纹相同的低频正常 POST 判定可有限复用；正文还原不完整、攻击判定、突发流量和配置变化不能复用。供应商前缀缓存与本地结果缓存分开统计，缓存本身不构成封禁证据。

## 处置与保护

自动处置需显式启用并符合阈值、近期时间窗、至少两条可核验请求和来源约束。旧日志、缺少原始时间或超出窗口的记录进入人工复核；按日前聚合保留真实历史时间，不用上传时间替代。

管理出口、面板地址、保护名单、WAF 白名单、保留/本机地址和人工解除保护参与检查。内网地址默认不自动封禁。真实客户端地址由受信采集链路确定，不能直接相信访客伪造的 X-Forwarded-For。

WAF 黑名单写入后再次查询核验。写入成功、WAF 开关生效、AF 同步是三个独立状态；失败、未知和待同步必须分别显示。清空全局名单、人工批量封禁和解除操作有业务影响，按团队变更流程执行。

“访问即加黑”适用于 SITE_RULE_DOMAIN 指定的独立无业务诱饵站点，默认禁用；正常业务门户不应使用。更换域名后隔离旧作用域并重新建立新增日志基线。

## 清洗规则与深度分析

清洗规则可按 IP/CIDR、方法、状态、路径和 UA 匹配，分为丢弃、存档、送审与必封。明确规则命中仍须遵守来源、本地模式与受保护地址约束。新增规则默认处理新增日志，历史扫描需单独发起。

深度分析聚合单 IP 的原始证据、攻击历史、保护状态与黑名单状态，支持对话复核。显示关联不等于确认人员身份；共享出口和同 UA 需要独立证据区分。

## AF、Syslog 与推送

AF 同步按本项目标记维护自己的条目；不接管其他系统创建的规则。名单读取不完整时停止本轮处理，写入后核验。同步删除在新配置中关闭。

Syslog 独立保存在 runtime/af-syslog.sqlite3，按授权设备来源接收。页面筛选不删除原文；退出时处理已接收待写入队列。协议、端口、字符编码、设备字段和防火墙来源规则需在目标设备上验收。

QQ 通知通过可选 OneBot HTTP 兼容服务发送，默认关闭。规则、去重、重试、群号与令牌属于现场配置；不随公开源码分发。

## API 与构建

面板接入位于 server.py，核心接口包括 websites/list、websites/{id}、files/download 及 xpack/waf 的状态、搜索、创建和删除。WAF 扩展接口在不同面板版本上可能不同，先以只读检查和 Mock 验证契约，再对目标环境验收。未捆绑从供应商页面抓取的脚本或 Swagger 副本。

独立黑名单导出接口使用 Bearer 专用凭据，与模型、面板和 Agent 令牌分离；见 [黑名单 API](blacklist-api.md)。网络入口的 TLS 与来源限制见仓库 Nginx 示例。

Agent 可从源码运行或自行用 PyInstaller 构建。公开包不包含运行库、实际令牌、历史二进制或 GeoIP 数据库。自动构建命令见模块 README。
