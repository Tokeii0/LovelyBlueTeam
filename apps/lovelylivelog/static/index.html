      接入 Windows 日志服务器
      每台服务器生成独立代理包。解压到对应服务器后，双击 run.cmd 即可开始采集，无需安装 Python。
      填写该服务器能访问的地址，使用平台的内网 IP 或 HTTPS 域名。远程服务器不能使用 127.0.0.1。
      路径用 {date} 代表日期（YYYY-MM-DD），例如 C:/nginx/logs/access_{date}.log。每天 00:30 后读取前一天的文件及相邻日期文件，只保留当天时间的记录，去掉静态资源后按 IP / 请求聚合；可疑和少见错误请求送 AI，其余仅存档。
      至少填写一条日志路径。支持 * 匹配日期文件；后续新文件从开头增量读取。默认 UTF-8。需要开机运行时，以管理员身份运行 install.cmd。
