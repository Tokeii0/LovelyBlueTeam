# 越权访问与敏感信息暴露

选择两组授权测试账号和人工构造的数据，验证服务端是否把当前身份与目标记录的归属关系绑定。只需最小数量的对照请求证明问题，不应枚举真实人员档案。

分别记录未登录、本人记录、另一测试账号记录、随机不存在 ID 的响应差异。数据加密、前端隐藏菜单或固定租户参数都不能替代服务端授权。响应被解密也不自动证明数据库范围，应以测试记录和后端审计核对。

临时缓解可针对具体接口限制访问与速率，根本修复应在服务层实施记录级授权与租户隔离，并覆盖读写接口和导出接口。修复后使用同样四组对照验证，无需附真实姓名、身份证、医疗或支付数据。

报告使用资产与账号代号；仅描述字段种类、授权边界和可确认的影响范围，原始敏感响应放入受控证据区。
