# 关联分析与隔离诱饵

将来源 IP、时间窗口、URI 序列、请求正文特征、文件哈希、后端轨迹、设备事件分别建表。先证明事件关联，再讨论基础设施复用；相同 UA、地理位置、云服务商或公开账号只能构成候选线索。

涉及 AI Agent 时，将任务指令、模型计划、工具执行结果和服务端证据分开。自动化访问不能单独识别 DeepSeek Harness 或 Computer Use；通过测试端主动提供的版本与执行记录确认。相关演练假设见[蜜罐设计](../docs/honeypot-design.md)，命令执行与证据边界见 [AI Agent 工作流](../docs/ai-agent-workflows.md)。

归因报告分为“已观察事实”“关联推断”“待核验假设”，每项附证据定位和反例。代理、VPN、共享出口及被控主机会破坏来源等于操作者的假设。对外版本不转录姓名、手机号、群成员或未经核实的人员画像。

诱饵站点部署在隔离网络，使用合成账号与数据，限制出口，不与生产凭据、业务网或真实患者数据相连。记录自己控制系统上的请求与行为用于检测验证。站点访问规则默认关闭，只有明确的无业务诱饵资产才适用。

本项目参考材料中的主动欺骗经验被整理为隔离部署与证据记录方法，未附向访问者计算机投递程序、执行代码或反向获取终端资料的流程。
