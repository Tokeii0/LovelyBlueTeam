# SQL 注入与参数类型约束

收到 SQL 特征告警后，确认请求的业务方法、字段路径、原始/解码表示及数据库调用。记录是否只是攻击字符串、产生数据库异常，或已经存在查询、写文件、出站 DNS 等独立证据。

JSON 数字字段应由应用按数据类型、范围和业务枚举验证；ORM/数据库调用使用参数化查询。不能通过 Nginx 的 URI 关键字正则完整检查 JSON 正文；被加密的正文必须在解密后的可信应用边界验证。

本项目 OpenResty 参数模块用于已知方法的临时类型约束，部署前确认业务允许值、字段可缺省性、POST/GET body、压缩、文件缓冲、大小限制与错误码。既有 WAF 阶段保持不变，禁止用另一 location 的同阶段 Lua 意外覆盖。

对于疑似外带，DNS 查询字符串只说明构造了载荷；需受控 DNS、出口流量、数据库或主机证据交叉确认。不要将公网地址归属、状态码或延时单独等同于成功外泄。
