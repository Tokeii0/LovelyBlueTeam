# 文件下载与文档转换服务

使用两个授权测试账号和无敏感内容的测试文件，检查下载接口是否绑定文件归属、租户与当前登录身份。分别验证本人文件、其他测试账号文件、不可达路径和不存在文件；不读取真实用户资料证明漏洞。

路径应经过服务端规范化后限制在指定存储根目录，拒绝任意绝对路径、跨目录和符号链接越界。客户端传入的文件名、URL、转换结果路径和前端参数不能作为授权依据。文件标识与存储路径分离，下载由受控接口返回。

文档转换服务按任务授权读写文件，输出到独立不可执行目录。限制允许格式、文件大小、超时、任务数量和网络出口；转换进程使用低权限账号。接口返回成功后，仍需验证实际落地位置、文件类型与可访问范围，不能由响应字段直接推定代码执行。

临时缓解限定受影响接口和调用来源，避免整体停用业务下载。变更后复测正常文件、预览、转换、附件回调与无权限访问，并在报告里分别写出入口缓解和根因修复。
